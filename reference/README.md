# glorb reference collection

This folder contains the retained island, character, audio, model, interface assets, and replicated boot pages used for reference work on **glorb**. Serve this folder as a static site to run the local reference build.

## Layout

| Path | What it is |
| --- | --- |
| `index.html` | Local reference boot page |
| `reference.html` | Duplicate boot page for reference inspection |
| `assets/` | Neutralized locale data, bundles, models, audio, fonts, and image assets |
| `assets/databeach-logo.png` | glorb wordmark (white type, transparent plate) |
| `favicon.ico` | Site favicon |
| `vendors/draco/` | Draco decoder files used by the retained model assets |
| `share/share_en.png` | glorb share graphic |
| `.gltf/` | Logical model names mapped to local files |
| `MANIFEST.json` | Preserved asset inventory with neutral local paths |

Technology-partner logos were replaced with transparent placeholders and the 16 partner slots are labeled **TECH COMPANY #1** through **TECH COMPANY #16** in the locale data. The boot pages retain the original runtime structure while using the neutralized glorb copy and assets.
