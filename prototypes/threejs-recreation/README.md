# Archived Three.js recreation

This folder preserves the source-level Three.js recreation made on September 2, 2026.
It is intentionally inactive and is not imported by the DATAB-EACH game at the repository root.

The snapshot includes the recreated renderer, alien character controller, animations, Cove
manifest, quests, interaction state, audio layer, portrait UI, and its Playwright test. Its asset
URLs refer to the preserved files in the repository's top-level `reference` folder.

The active game remains the exact reference implementation served from `reference/index.html`.
Keeping this archive does not change that game, its dependencies, or its runtime behavior.
